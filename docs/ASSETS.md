# Visual assets

The local MVP uses remote Unsplash image delivery for four illustrative interior photos, referenced in `lib/catalog.ts`. They are not supplier portfolio images or evidence of completed projects. Google Fonts supplies DM Sans and Manrope; system fonts are fallbacks. Both depend on network availability and send ordinary asset requests to their respective providers. Review final licensing, attribution and hosting requirements before a commercial launch.

The interface uses a charcoal, warm-white and restrained-bronze palette, large editorial typography, detailed supplier cards and restrained project imagery. There are no invented client logos, reviews, ratings or supplier counts.

## Revised apartment-community hero

The hero and multifamily/garden-style sourcing guides now use Aalo Lens’s “Modern apartment building with balconies and greenery,” published on Unsplash under its free-use license. This directly reflects the founder’s request to show apartments rather than a single-family kitchen. It is illustrative, not a Clutch project.

## Moving hero and revised identity

The homepage uses a 22-second CSS image sequence: an apartment exterior push-in, a crossfade into an apartment kitchen, then a return to the exterior. These are separate illustrative images, not a real continuous camera traversal or the same property's interior. A pause control and reduced-motion fallback are included.

Kitchen: Max Vakhtbovych, Pexels, https://www.pexels.com/photo/shot-of-an-empty-kitchen-in-an-apartment-for-rent-7546561/

The brand mark is an original SVG cabinet elevation with paired doors and bronze pulls, used consistently in the header, footer and favicon.
